# ☾ 달빛 편의점

**오늘 밤은, 당신의 선택대로.**

🎮 **[지금 플레이하기](https://seungjaehh.github.io/moonlight-store/)**

자정에 문을 여는 조금 이상하고 다정한 편의점. 고양이 점장, 길 잃은 편지, 목마른 달을 만나며 일곱 번의 선택으로 당신의 밤을 완성하는 한국어 웹게임입니다.

## 플레이

- 약 3분, 일곱 번의 선택과 여덟 가지 결말
- 첫 선택과 소지품에 따라 달라지는 사건과 인물의 반응
- 온기·호기심·용기 기록, 소지품, 선택 내역 영수증
- 진행 상황 자동 저장, 결말 수첩 및 미발견 결말 힌트
- 모바일 지원, 숫자 1·2·3 선택, 선택 후 Enter로 계속
- 선택 음향(기본 꺼짐), 시스템의 움직임 줄이기 설정 지원
- 로그인·서버·결제·광고·분석 추적 없음

저장은 브라우저 localStorage를 사용합니다. 브라우저 데이터 삭제 또는 시크릿 모드 종료 시 기록을 잃을 수 있습니다. 여러 기기 사이에는 동기화하지 않습니다. Google Fonts를 불러오며 연결되지 않으면 시스템 글꼴을 사용합니다. 게임과 벡터 그림은 외부 API 없이 동작합니다.

## 로컬 실행

Node.js 18+ 및 Python 3로 추가 패키지 설치 없이 실행할 수 있습니다.

```sh
npm test
npm start
```

브라우저에서 http://localhost:4173 을 엽니다. `dist/` 안의 파일 전체가 정적 웹사이트입니다. 모듈을 사용하므로 파일을 직접 여는 대신 HTTP 서버로 실행하세요.

수정한 뒤 `npm run build`로 GitHub Pages용 `docs/`를 갱신하고 함께 커밋하세요. GitHub Actions가 게임 경로와 배포 파일 동기화를 검사합니다.

## 구조

`dist/game.mjs`는 순수 상태 전이와 분기, `dist/app.mjs`는 UI와 저장, `dist/art.mjs`는 직접 제작한 SVG 일러스트입니다. `tests/game.test.mjs`는 가능한 2,187개 경로, 결말 도달 가능성, 상태 복원과 불변성을 검증합니다.

결말은 누적된 인연·물건·행동과 마지막 선택으로 결정됩니다. 능력치에는 실패 조건이 없으며, 선택의 성향을 기록하는 역할입니다. GitHub Pages는 main 브랜치의 `/docs`를 배포하며 `/docs`는 검증한 `dist`와 같은 내용입니다.
