# ! 멸망 10분 전

**세상은 망하고, 선택은 남는다.**

🎮 **[지금 플레이](https://seungjaehh.github.io/moonlight-store/)**

달의 파업, 고양이 정권, 지구 서버 종료, 무한 월요일. 터무니없는 재난 속에서 사람을 구하고, 자원을 챙기고, 때로는 동료를 배신하는 한국어 선택형 블랙코미디 생존 게임입니다. 기존 달빛 편의점의 고정 결말 구조를 전면 교체했습니다. 기존 버전 소스는 Git 기록에 남아 있습니다.

## 실제로 달라지는 선택

- 한 판 최대 10번의 선택. 선택 한 번이 가상 시간 1분이며 실시간 제한은 없습니다. 체력이 0이면 일찍 끝납니다.
- 4개 재난과 18개 기본 사건을 시드 및 이전 선택에 따라 조합합니다. 한 판에서 같은 기본 사건은 반복하지 않습니다.
- 가져간 가방의 주인, 미래의 나에게 빌려준 돈, 도움을 받은 사람, 범죄 이후 검문 등 후속 사건이 예약되어 돌아옵니다.
- 체력·돈·잔머리·신뢰·악명은 실제 선택 가능성과 결과에 영향을 줍니다. 능력치 검사 결과를 선택 전에 확인할 수 있습니다.
- 10종 아이템은 상황에 맞는 네 번째 선택지를 열거나 마지막 탈출·협상에 사용됩니다. 쓴 물건은 사라집니다.
- 동료를 모집할 수 있고 배신하거나 신뢰가 무너지면 실제로 떠납니다.
- 마지막에는 방공호, 방송 협상, 도시 탈출, 세계 접수(또는 오리 정권)를 선택합니다. 준비한 물건과 관계에 따라 결과가 달라집니다.

## 결말 생성의 범위

8개 같은 고정된 결말 목록을 채우는 방식이 아닙니다. 실제 재난, 선택 경로, 생존 방식, 돌아온 사건, 관계, 동료, 남은 소지품과 자원을 바탕으로 제목과 5개 문단의 후일담을 구성합니다. 서사에서 참조한 선택의 전체 기록도 함께 보여 줍니다.

**절차적 조합형입니다. 실시간 AI 문장 생성은 아닙니다.** 사건 및 문구는 유한한 원본을 사용하므로 반복될 수 있고, 모든 판이 의미상 완전히 다른 내용이라고 보장하지 않습니다. 플레이 횟수와 결말 수집 개수에 인위적인 제한을 두지 않았습니다. 여러 시드가 같은 제목을 만들더라도 세부 경로와 후일담은 달라질 수 있습니다.

## 저장 및 공유

진행과 완성한 기록은 `localStorage`에 저장합니다. 현재 진행은 선택 경로를 재생하여 복원합니다. 공유 링크는 재난 시드와 선택 경로를 담아 같은 결말을 재현하고, 받은 기록을 보더라도 내 진행은 덮어쓰지 않습니다. 같은 재난을 다른 선택으로 다시 플레이할 수도 있습니다.

기기 간 동기화는 없습니다. 브라우저 데이터를 삭제하면 기록이 사라지며, 저장 용량 및 권한 제한이 있으면 안내합니다. 모은 기록에 앱 자체의 개수 제한은 없지만 브라우저 저장 공간에는 한계가 있습니다. 구버전 달빛 편의점 저장 키는 건드리지 않습니다.

## 개발

Node.js 18+와 Python 3를 사용합니다. 의존성 설치 없이 실행할 수 있습니다.

```sh
npm test
npm start
```

http://localhost:4173 에 접속합니다. 파일을 직접 열지 말고 HTTP 서버를 사용하세요.

```sh
npm run build
```

검증한 `dist/`를 GitHub Pages용 `docs/`로 복사합니다. 두 폴더를 함께 커밋하세요. Pages는 main의 `/docs`를 배포합니다. GitHub Actions가 엔진 테스트 및 배포 파일 동기화를 검사합니다.

- `dist/events.mjs`: 사건과 선택, 조건부 선택지, 후속 사건
- `dist/survival.mjs`: 불변 상태 전이, 시드 기반 분기, 결말 구성과 공유 코드
- `dist/survival-app.mjs`: 화면, 저장, 수집 기록, 공유, 키보드와 음향
- `dist/survival-art.mjs`: 직접 제작한 재난·도시·사건 SVG
- `tests/survival.test.mjs`: 2,000개 생성 판의 종료·자원·복원, 인과관계, 아이템 소모, 배신, 비용 차단, 공유 코드와 마지막 선택 검증

서버, API 키, 결제, 로그인, 분석 추적은 없습니다. Google Fonts가 연결되지 않으면 시스템 글꼴로 동작합니다. 원래 코드·이야기·SVG는 MIT이며 외부 글꼴에는 해당 라이선스가 적용됩니다.
